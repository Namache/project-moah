# Security policy

## Supported versions

Only the [latest release](https://github.com/Namache/project-moah/releases/latest) gets security fixes.

## Report a vulnerability

Please don't open a public issue. Report it privately from this repository's **Security** tab with **Report a vulnerability**, or go straight to [a new private report](https://github.com/Namache/project-moah/security/advisories/new).

Say what you found, how to reproduce it, and which version and system you used. You will get an answer as soon as the report has been read, and credit in the fix's release notes if you want it.

## What counts

Project Moah is meant to stay on your computer. Anything that breaks that is a security problem, for example:

- the app or its agent connection reaching the network,
- another program or user on the computer reading or changing Moah's data through it,
- an agent changing locked memory without a person's OK.
