Project Moah даёт агентам локальный MCP-сервер. Он работает на вашем компьютере, и сеть ему не нужна.

## Шаги

1. **Установите и откройте Project Moah** хотя бы раз, чтобы появились его данные.
2. **Подключите Claude Code один раз.** Одно подключение обслуживает все проекты: Project Moah находит проект по папке, в которой работает Claude Code, а ваши [общие правила](/global) действуют везде, даже вне проекта.
3. **Проверьте.** Выполните `claude mcp list` или наберите `/mcp` внутри Claude Code.
4. **Испытайте.** Начните новую сессию в папке проекта и спросите, каким правилам он следует. Он должен перечислить ваши общие правила и назвать проект.

{{snippet:claude}}

**Зачем загружать правила в начале?** Второй фрагмент передаёт Claude ваши общие правила, правила проекта, фокус и последнюю контрольную точку ещё до вашего первого сообщения, в каждой сессии. Без него Claude получает их, только если сам решит спросить, а часто он не спрашивает. Если правила у вас уже загружаются сами, этот шаг уже настроен.

{{only flatpak}}
Агент работает в контейнере, например distrobox? Подключение работает как показано, потому что команда `flatpak` передаётся на основную систему. Чтобы Project Moah мог читать репозиторий для «Файлов» и Git, см. [[troubleshooting-container]].
{{end}}
{{only deb}}
Команда `project-moah-mcp` установлена вместе с приложением, поэтому эти команды работают из любой папки.
{{end}}
{{only windows}}
Выполняйте эти команды в PowerShell. В них указана папка, куда Project Moah установлен на этом компьютере, поэтому если переустановите его в другое место, скопируйте команды заново.
{{end}}
