Project Moah keeps your tasks, decisions and development memory in one place, so a coding agent can pick up where the last one stopped without rereading everything.

## The first five minutes

1. **Create a project.** Choose *Projects*, then *New project*. A project is a separate home for one product or codebase.
2. **Connect a repository.** Choose the folder your code lives in, or skip this and add it later.
3. **Add a task.** For example, "Implement save migration". Give it acceptance criteria so everyone knows when it is done.
4. **Record a decision.** Open *Memory* and add something you have decided, such as "Maximum party size is 4."
5. **Preview what an agent would receive.** Open *AI Context* to see the Context Pack for your task.
6. **Connect Claude Code or Codex** using the guides in this Help section.

Everything stays on this computer. No account is needed.
