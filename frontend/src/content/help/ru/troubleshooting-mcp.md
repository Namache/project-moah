## Проблема

Агент не может запустить сервер Project Moah или связаться с ним.

## Вероятные причины

- Project Moah не установлен или ни разу не открывался.
- Команда подключения изменена или набрана с ошибкой.
- Агент не перезапустили после добавления сервера.
- Сервер добавлен не с той областью действия.

## Как исправить

1. Проверьте, что Project Moah установлен и хотя бы раз открывался.
2. Выполните команду подключения заново, взяв её из инструкции по подключению.
3. Перезапустите агента, затем выполните `claude mcp list` или `codex mcp list`.
4. Сам Project Moah продолжает работать, даже если подключение не удалось.
