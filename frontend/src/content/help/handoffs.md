A **handoff** is a short plain-text note for switching between agents or sessions. It lists the task, what is completed, what remains, the next action, important decisions, known issues, relevant files and the latest checkpoint.

Use *Copy handoff* on the focus card, in a task, or on the *AI context* page, then paste it into any coding agent. It works with every agent because it uses no special syntax.
