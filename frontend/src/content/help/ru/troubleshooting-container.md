## Проблема

Вы запускаете Claude Code или Codex в контейнере, например distrobox, и Project Moah говорит, что папка репозитория недоступна, хотя агент её видит.

## Вероятные причины

- **Три взгляда на одну папку.** Агент видит ваши файлы через контейнер, например `/home/you/project`. На основной системе та же папка лежит в `/var/home/you/project`. Project Moah работает в своей песочнице Flatpak и не видит ни того, ни другого, пока вы не откроете ему доступ к папке.
- **Само подключение в порядке.** Внутри контейнера команда `flatpak` передаётся на основную систему, поэтому агент запускает Project Moah правильно. Задачи, записи, контекст, контрольные точки и предложения работают. Скрыта только папка репозитория.
- **Песочница так задумана.** Приложению не выдан доступ к вашим домашним папкам, поэтому оно читает только то, что вы сами откроете.

## Как исправить

1. **Проще всего:** измените проект в Project Moah и нажмите **Выбрать папку**. Системное окно выбора откроет доступ только к этой папке.
2. **Или откройте доступ одной командой, только для чтения.** Выполните её один раз, в контейнере или на основной системе. Берите папку из сообщения Project Moah — там точная команда для вашего проекта:

```bash
flatpak override --user --filesystem=~/projects/my-project:ro io.github.projectbrain.ProjectBrain
```

3. Откройте проект заново. Страница «Файлы» должна показать ветку и изменения.
4. Чтобы отменить: `flatpak override --user --nofilesystem=~/projects/my-project io.github.projectbrain.ProjectBrain`.

Доступ открывается **только для чтения**, поэтому Project Moah может читать имена файлов, состояние Git и сообщения коммитов и никогда не сможет изменить ваш код. Остальные папки остаются скрытыми.

Если он по-прежнему говорит, что папка не является репозиторием Git, значит, так и есть. Проверьте, выполнив там `git status`.
