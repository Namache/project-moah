Страница *Файлы* показывает файлы репозитория с заметками о том, зачем нужен каждый. Project Moah хранит заметки, но никогда не хранит ваш исходный код и никогда не меняет репозиторий.

## Заметки о файлах

Добавьте назначение, краткое описание, важные символы и связи с задачами и решениями, которые относятся к файлу. Тогда агенты знают, какой файл открывать первым. Если файл изменился после вашей последней проверки заметок, вы это увидите.

## Git

Project Moah читает ветку, состояние рабочей копии и недавние коммиты. Номер задачи в сообщении коммита показывается как предложение и становится связью, только когда вы его подтвердите.

Если Git или папка недоступны, вы увидите почему, а всё остальное продолжит работать.
{{only windows}}
Для ветки и коммитов нужен Git for Windows. Без него заметки о файлах всё равно работают.
{{end}}
