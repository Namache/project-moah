## Проблема

Не видно ветки, изменений или коммитов.

## Вероятные причины

- Git недоступен для Project Moah.
- Папка не является репозиторием Git или в нём ещё нет коммитов.
- Git отказался открыть репозиторий из-за владельца папки.

## Как исправить

1. Откройте *Файлы* и прочитайте сообщение вверху — в нём названа причина.
2. Убедитесь, что папка — репозиторий Git хотя бы с одним коммитом.
3. Исправьте владельца папки или попросите Git доверять ей.
