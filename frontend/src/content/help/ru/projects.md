**Проект** держит вместе задачи, записи, файлы и активность одного продукта. Проекты никогда не смешиваются: агент, работающий над одним, не получает решений другого, если только вы сами не ищете по всем проектам.

## Работа с проектами

- **Создайте** проект на странице *Проекты*. Папку репозитория можно добавить сразу или позже.
- **Переключайтесь** через список проектов на боковой панели. Недавно открытые проекты идут первыми.
- **Отправьте в архив** проект, которым не пользуетесь. Архив сохраняет все данные и никогда не трогает ваш исходный код. Проект можно восстановить в любой момент.

## Номера задач

У каждого проекта есть короткий префикс для номеров задач, например CAMP в CAMP-037. Он берётся из названия проекта, а номера уникальны внутри проекта.

## Синхронизация с агентами

Создавать проекты вручную приходится редко. Project Moah смотрит, в какой папке запускалась каждая сессия Claude Code и Codex, и создаёт по проекту на каждую такую папку, называя его по имени папки. Он проверяет это каждую минуту, пока приложение открыто, и ещё раз всякий раз, когда агент начинает сессию.

- Временные папки, рабочие копии (worktree) и одноразовые папки чатов Codex пропускаются. Работа в подпапке засчитывается её проекту.
- Если папка похожа на существующий проект, у которого ещё нет папки, Project Moah не гадает, а спрашивает на странице *Проекты*. Выберите **Да**, **Нет, создать новый проект** или **Пропустить папку**.
- Папка пропущенного или архивного проекта больше не возвращается. Чтобы отменить пропуск, откройте список **Найдено папок**.
- Читается только путь к папке, никогда — то, о чём шла речь в сессии.
