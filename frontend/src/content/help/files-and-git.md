The *Files* page shows your repository's files with notes about what each is for. Project Moah stores notes, never your source code, and never changes your repository.

## File notes

Add a purpose, a summary, important symbols, and links to the tasks and decisions that relate to a file. Agents then know which file to open first. If a file changes after you last reviewed its notes, you are told so.

## Git

Project Moah reads the branch, working tree status and recent commits. A task ID in a commit message is shown as a suggestion; it only becomes a link when you confirm it.

If Git or the folder is unavailable you see why, and everything else keeps working.
{{only windows}}
Branch and commit details need Git for Windows. Without it, file notes still work.
{{end}}
