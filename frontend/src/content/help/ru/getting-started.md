Project Moah хранит ваши задачи, решения и память разработки в одном месте, чтобы агент для программирования мог продолжить с того места, где остановился предыдущий, не перечитывая всё заново.

## Первые пять минут

1. **Создайте проект.** Нажмите *Создать*, затем *Новый проект*. Проект — отдельный дом для одного продукта или кодовой базы. Можно и просто открыть папку с кодом в Claude Code или Codex: Project Moah сам создаст для неё проект.
2. **Подключите репозиторий.** Выберите папку с вашим кодом или пропустите этот шаг и добавьте её позже.
3. **Добавьте задачу.** Например, «Сделать миграцию сохранений». Добавьте критерии приёмки, чтобы всем было ясно, когда задача готова.
4. **Запишите решение.** Откройте *Память* и добавьте то, что вы решили, например «В отряде не больше 4 героев».
5. **Посмотрите, что получит агент.** Откройте *Контекст для ИИ*, чтобы увидеть пакет контекста для вашей задачи.
6. **Подключите Claude Code или Codex** по инструкциям в этом разделе справки.

Всё остаётся на этом компьютере. Учётная запись не нужна. Язык можно переключить между английским и русским в *Настройках*.
